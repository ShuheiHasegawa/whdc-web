実装方法

1. 静的ファイルの配置
   旧 IR ページの HTML、CSS、JS 等のファイル一式を public/news/ir/ディレクトリに配置します。

2. リダイレクト設定
   Next.js でリダイレクトを設定するには、next.config.js に以下のような設定を追加します

3.旧ファイルのパス修正
旧 IR ページ内のリンクパスを修正します。例えば：
絶対パスの場合：/css/style.css → /news/ir/css/style.css
相対パスの場合：既に相対パスなら修正不要の場合もあります

4. 旧 IR ページから新ページへのリンク修正
   旧 IR ページから新ページへのリンクが相対パスになっている場合、一階層深くなったことを考慮して修正します。
   例：
   <a href="/company/">会社概要</a> → <a href="/../../company/">会社概要</a>
   または絶対パスに変更：<a href="https://www.twhdc.co.jp/company/">会社概要</a>
   メリットと注意点
   メリット
   外部からの古いリンクが切れることなく、正しく新しい場所にリダイレクトされます
   検索エンジンのインデックスも徐々に新しい場所に更新されます
   静的ファイルは Next.js のビルド処理を通さずそのまま配信されるため、古い HTML/CSS がそのまま動作します
   注意点
   リダイレクト設定はサーバーサイドで処理されるため、静的エクスポート（next export）使用時は別途サーバー設定が必要です
   全てのパスを正確にリダイレクトできるよう、設定を慎重に行う必要があります
   古いファイル内の相対パスが複雑な場合、修正作業が発生する可能性があります
   まとめ
   旧 IR ページを/news/ir/に配置し、元の/ir/パスからリダイレクトさせることは十分実現可能です。これにより、外部リンクの保全と SEO 価値の保持ができます。
   修正する際は以下の点に留意してください：
   ファイルの適切な配置
   Next.js でのリダイレクト設定
   旧ファイル内のパス参照の修正
   全てのリンクが正しく機能するかのテスト
